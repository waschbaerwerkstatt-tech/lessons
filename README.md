## Deployment

GitHub Pages wird aus dem Root des `main`-Branches gebaut. Neue oder
geaenderte Lernressourcen werden nach einem Push auf `main` automatisch ohne
Kennwort veroeffentlicht, solange das Repository public bleibt.
